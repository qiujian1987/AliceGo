# 分类管理特性需求规约

## 1. 特性基本信息

- **特性ID**：feature-002
- **特性名称**：分类管理特性
- **所属模块**：个人笔记应用
- **优先级**：高
- **负责人**：@backend-dev / @frontend-dev
- **创建日期**：2026-05-17

## 2. 用户故事

- 作为**用户**，我要**为笔记添加分类标签**，以便**更好地组织我的笔记**
- 作为**用户**，我要**按分类筛选笔记**，以便**快速找到特定类型的笔记**

## 3. 功能需求

### 3.1 添加分类标签

- **FR-002-001**：用户在创建笔记时可以添加分类标签
- **FR-002-002**：用户在编辑笔记时可以修改分类标签
- **FR-002-003**：分类标签为可选字段
- **FR-002-004**：支持同时为多个笔记设置相同的分类

### 3.2 按分类筛选

- **FR-002-005**：用户可以按分类标签筛选笔记列表
- **FR-002-006**：支持"全部分类"选项，显示所有笔记
- **FR-002-007**：筛选操作实时响应，无需刷新页面

### 3.3 分类管理

- **FR-002-008**：显示所有已使用的分类标签列表
- **FR-002-009**：显示每个分类下的笔记数量
- **FR-002-010**：支持查看某个分类下的所有笔记

## 4. 数据需求

### 4.1 数据实体

- **Category（分类）**：
  - name: TEXT (分类名称, 必填, 最大50字符)
  - note_count: INTEGER (该分类下的笔记数量)

### 4.2 数据关系

- 一个笔记属于一个分类（可选）
- 一个分类包含多个笔记（可选）

### 4.3 数据格式

- 分类名称：UTF-8编码字符串，最大50字符
- 不区分大小写（"Work"和"work"视为同一分类）

## 5. 界面需求

### 5.1 笔记编辑页面

- 分类输入：下拉选择框 + 可输入新分类
- 分类显示：已选中分类以标签形式显示

### 5.2 笔记列表页面

- 分类筛选：下拉选择框，显示所有已使用的分类
- 分类显示：笔记卡片显示所属分类标签

### 5.3 分类管理页面

- 分类列表：显示所有分类及笔记数量
- 点击分类：跳转到该分类的笔记列表

## 6. 验收标准

- **AC-002-001**：用户能够在创建笔记时添加分类标签
- **AC-002-002**：用户能够在编辑笔记时修改分类标签
- **AC-002-003**：用户能够按分类筛选笔记列表
- **AC-002-004**：分类筛选能够正确显示对应分类的笔记
- **AC-002-005**：分类列表能够显示所有分类及笔记数量

## 7. 技术约束

### 7.1 性能要求

- 分类列表加载时间 < 500ms
- 分类筛选响应时间 < 300ms

### 7.2 安全要求

- 防止SQL注入攻击
- 验证分类名称的长度和格式

### 7.3 兼容要求

- 支持主流浏览器
- 响应式设计

## 8. 依赖关系

### 8.1 前置依赖

- **feature-001（笔记管理）**：必须在分类管理之前实现，因为需要先有笔记才能添加分类

### 8.2 后置依赖

- **feature-003（搜索功能）**：搜索可以结合分类筛选使用

### 8.3 外部依赖

- SQLite 数据库
- Express.js + TypeScript
- React + TypeScript

## 9. 风险与假设

### 9.1 潜在风险

- 分类数量过多可能导致界面拥挤
- 分类命名不一致（如"Work"和"work"）

### 9.2 假设条件

- 假设用户会合理使用分类标签
- 假设分类数量不会过多（一般不超过20个）

### 9.3 应对策略

- 对分类名称进行统一处理（统一转为小写或首字母大写）
- 在界面上限制分类数量或提供分页
