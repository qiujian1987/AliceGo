### 1. 搜索笔记

**端点**：`GET /api/notes/search`

**查询参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| q | string | 是 | - | 搜索关键词（最大100字符） |
| limit | integer | 否 | 20 | 返回数量（最大100） |

## 搜索特性

### 1. 搜索范围

- 搜索范围包括笔记标题（title）
- 搜索范围包括笔记内容（content）
- 搜索使用 SQLite FULLTEXT 索引

### 2. 搜索算法

- 使用 FTS5（Full-Text Search 5）虚拟表
- 支持布尔模式搜索
- 支持模糊匹配（使用 Porter 分词器）
- 搜索不区分大小写

### 3. 搜索性能

- 响应时间目标：< 1秒
- 支持至少 1000 条笔记的搜索
- 使用 FULLTEXT 索引优化查询性能

### 4. 搜索限制

- 搜索关键词最大100字符
- 建议搜索关键词长度 ≥ 2字符

## 错误处理

| HTTP 状态码 | 错误码 | 场景 |
|------------|--------|------|
| 400 | VALIDATION_ERROR | 搜索关键词为空或过长 |
| 500 | INTERNAL_ERROR | 服务器错误 |

### 错误响应示例

**400 验证错误**：
```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "搜索关键词不能为空",
    "details": {
      "field": "q",
      "reason": "必填字段"
    }
  }
}
```
