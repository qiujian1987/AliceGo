## 3. 边界条件测试

#### TC-003-B-001：关键词长度边界
- **测试类型**：边界值
- **测试步骤**：
  1. 搜索关键词为100字符（最大长度）
  2. 搜索关键词为101字符（超过最大长度）
- **预期结果**：100字符成功搜索，101字符返回验证错误
- **对应功能**：FR-003-001

#### TC-003-B-002：特殊字符搜索
- **测试类型**：边界值
- **测试步骤**：
  1. 搜索包含特殊字符的关键词：`test & query`
  2. 搜索包含正则表达式的关键词：`test.*query`
- **预期结果**：特殊字符被正确转义，不会导致查询错误
- **对应功能**：FR-003-001

#### TC-003-B-003：中文搜索
- **测试类型**：边界值
- **测试步骤**：
  1. 搜索中文关键词"会议"
  2. 搜索中文关键词"项目进度"
- **预期结果**：正确返回包含中文关键词的笔记
- **对应功能**：FR-003-001, FR-003-002

#### TC-003-B-004：模糊搜索
- **测试类型**：边界值
- **测试步骤**：
  1. 搜索关键词"会"
  2. 搜索关键词"议"
- **预期结果**：FTS5支持前缀匹配，返回相关结果
- **对应功能**：FR-003-001, FR-003-002

#### TC-003-B-005：SQL注入测试
- **测试类型**：安全测试
- **测试步骤**：
  1. 在搜索框输入SQL注入代码：`'; DROP TABLE notes; --`
- **预期结果**：SQL注入代码被转义或过滤，不会影响数据库
- **对应功能**：FR-003-001（安全性）

#### TC-003-B-006：XSS测试
- **测试类型**：安全测试
- **测试步骤**：
  1. 在搜索框输入XSS代码：`<script>alert('xss')</script>`
- **预期结果**：XSS代码被转义，不会被执行
- **对应功能**：FR-003-001（安全性）
