## 任务描述

实现笔记搜索功能的前端UI：

1. **搜索框组件**
   - 实现搜索输入框
   - 实现搜索按钮
   - 实现防抖功能（300ms）

2. **搜索结果展示**
   - 实现搜索结果列表
   - 实现搜索结果高亮
   - 实现搜索结果统计
   - 实现空结果提示

3. **搜索交互**
   - 实现搜索历史（可选）
   - 实现URL参数同步
   - 实现返回按钮
