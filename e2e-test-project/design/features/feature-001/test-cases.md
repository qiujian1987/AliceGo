- **测试类型**：边界值

  1. 创建标题为255字符的笔记（最大长度）

#### TC-001-B-002：空内容笔记
- **测试类型**：异常处理
- **测试步骤**：
  1. 尝试创建内容为空的笔记
- **预期结果**：返回验证错误，提示内容不能为空
- **对应功能**：FR-001-002

#### TC-001-B-003：笔记列表分页边界
- **测试类型**：边界值
- **测试步骤**：
  1. 请求page=0
  2. 请求page=-1
  3. 请求limit=0
  4. 请求limit=1000（超过最大限制）
- **预期结果**：page<1自动调整为1，limit超出范围自动限制
- **对应功能**：FR-001-005

#### TC-001-B-004：SQL注入测试
- **测试类型**：安全测试
