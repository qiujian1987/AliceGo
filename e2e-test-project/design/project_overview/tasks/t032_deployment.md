## 部署流程

```bash
# 1. 构建前端
npm run build

# 2. 构建后端
npm run build:server

# 3. 配置环境变量
cp .env.example .env

# 4. 初始化数据库
npm run db:init

# 5. 启动服务（使用PM2）
pm2 start ecosystem.config.js
```
