# 个人笔记应用测试需求

## 项目概述

创建一个简单的个人笔记应用，用于验证 AliceGo 框架的端到端流程。

## 功能需求

### 1. 笔记管理
- 用户可以创建笔记（标题、内容）
- 用户可以查看笔记列表
- 用户可以查看单条笔记详情
- 用户可以编辑笔记
- 用户可以删除笔记

### 2. 分类管理
- 用户可以为笔记添加分类标签
- 用户可以按分类筛选笔记

### 3. 搜索功能
- 用户可以根据关键词搜索笔记

## 技术要求

### 后端
- 使用 Express.js + TypeScript
- 使用 SQLite 数据库
- RESTful API 设计

### 前端
- 使用 React + TypeScript
- 简洁的用户界面

### 测试
- 单元测试覆盖率 ≥ 80%
- 集成测试覆盖核心功能

## 验收标准

1. 用户可以完成笔记的 CRUD 操作
2. 用户可以按分类筛选笔记
3. 用户可以搜索笔记
4. 所有 API 都有对应的测试用例
5. 代码通过 lint 和 type check
