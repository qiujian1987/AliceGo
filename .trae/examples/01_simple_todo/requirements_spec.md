# 简单待办事项应用 - 需求规约

## 1. 项目概述

### 1.1 项目基本信息

| 项目属性 | 值 |
|---------|-----|
| 项目名称 | Simple Todo |
| 项目类型 | Web 应用 |
| 项目目标 | 提供简单易用的待办事项管理工具 |
| 目标用户 | 需要管理日常任务的个人用户 |

### 1.2 核心功能

用户可以：
- 注册和登录账户
- 创建、查看、更新、删除待办事项
- 为待办事项添加分类标签
- 标记待办事项为已完成
- 导出待办事项列表

---

## 2. 业务需求

### 2.1 用户管理

- **用户注册**：用户通过邮箱和密码注册账户
- **用户登录**：用户通过邮箱和密码登录系统
- **用户登出**：用户退出登录状态
- **会话保持**：登录状态持续 7 天

### 2.2 任务管理

- **创建任务**：用户创建新的待办事项
- **查看任务**：用户查看自己的所有待办事项
- **更新任务**：用户修改待办事项的标题、描述、截止日期
- **删除任务**：用户删除不需要的待办事项
- **完成任务**：用户标记待办事项为已完成

### 2.3 分类管理

- **创建分类**：用户创建自定义分类（如"工作"、"生活"）
- **编辑分类**：用户修改分类名称
- **删除分类**：用户删除分类（任务不会被删除）
- **分配任务**：用户将待办事项分配到某个分类

### 2.4 数据导出

- **导出格式**：支持导出为 CSV 格式
- **导出范围**：可以导出所有任务或仅已完成的任务

## 4. 非功能需求

### 4.1 性能需求

| 指标 | 要求 |
|------|------|
| 页面加载时间 | < 2 秒 |
| API 响应时间 | < 500ms |
| 并发用户数 | 支持 100 个并发用户 |

### 4.2 安全需求

| 需求 | 说明 |
|------|------|
| 密码加密 | 使用 bcrypt 加密存储 |
| JWT 有效期 | 7 天 |
| HTTPS | 所有请求必须使用 HTTPS |
| SQL 注入防护 | 使用参数化查询 |
| XSS 防护 | 输入输出转义 |

### 4.3 可用性需求

| 指标 | 要求 |
|------|------|
| 系统可用性 | 99.5% |
| 备份频率 | 每日备份 |
| 故障恢复时间 | < 1 小时 |

### 4.4 可维护性需求

| 指标 | 要求 |
|------|------|
| 代码覆盖率 | ≥ 80% |
| 文档完整性 | 完整 API 文档 |
| 代码规范 | ESLint + Prettier |

## 5. 数据需求

### 5.1 用户数据

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK | 用户唯一标识 |
| email | VARCHAR(255) | UNIQUE, NOT NULL | 邮箱地址 |
| password_hash | VARCHAR(255) | NOT NULL | 加密密码 |
| created_at | TIMESTAMP | NOT NULL | 创建时间 |
| updated_at | TIMESTAMP | NOT NULL | 更新时间 |

### 5.2 任务数据

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK | 任务唯一标识 |
| user_id | UUID | FK, NOT NULL | 所属用户 |
| category_id | UUID | FK, NULLABLE | 所属分类 |
| title | VARCHAR(255) | NOT NULL | 任务标题 |
| description | TEXT | NULLABLE | 任务描述 |
| due_date | DATE | NULLABLE | 截止日期 |
| completed | BOOLEAN | DEFAULT false | 完成状态 |
| created_at | TIMESTAMP | NOT NULL | 创建时间 |
| updated_at | TIMESTAMP | NOT NULL | 更新时间 |

### 5.3 分类数据

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK | 分类唯一标识 |
| user_id | UUID | FK, NOT NULL | 所属用户 |
| name | VARCHAR(100) | NOT NULL | 分类名称 |
| color | VARCHAR(7) | DEFAULT '#000000' | 分类颜色 |
| created_at | TIMESTAMP | NOT NULL | 创建时间 |
| updated_at | TIMESTAMP | NOT NULL | 更新时间 |

## 6. API 端点

### 6.1 认证 API

| 方法 | 端点 | 描述 |
|------|------|------|
| POST | /api/auth/register | 用户注册 |
| POST | /api/auth/login | 用户登录 |
| POST | /api/auth/logout | 用户登出 |

### 6.2 任务 API

| 方法 | 端点 | 描述 |
|------|------|------|
| GET | /api/tasks | 获取任务列表 |
| GET | /api/tasks/:id | 获取任务详情 |
| POST | /api/tasks | 创建任务 |
| PUT | /api/tasks/:id | 更新任务 |
| DELETE | /api/tasks/:id | 删除任务 |
| PATCH | /api/tasks/:id/complete | 标记完成 |

### 6.3 分类 API

| 方法 | 端点 | 描述 |
|------|------|------|
| GET | /api/categories | 获取分类列表 |
| POST | /api/categories | 创建分类 |
| PUT | /api/categories/:id | 更新分类 |
| DELETE | /api/categories/:id | 删除分类 |

### 6.4 导出 API

| 方法 | 端点 | 描述 |
|------|------|------|
| GET | /api/export/tasks | 导出任务 |

## 7. 验收标准

### 7.1 用户认证

- [ ] 用户可以使用邮箱和密码注册账户
- [ ] 用户可以登录并获得 JWT token
- [ ] 用户可以登出并清除登录状态
- [ ] 未登录用户无法访问受保护的 API

### 7.2 任务管理

- [ ] 用户可以创建包含标题的任务
- [ ] 用户可以查看自己的任务列表（分页）
- [ ] 用户可以修改任务的所有字段
- [ ] 用户可以删除任务
- [ ] 用户可以将任务标记为已完成
- [ ] 用户可以筛选任务（按状态、分类）

### 7.3 分类管理

- [ ] 用户可以创建自定义分类
- [ ] 用户可以修改分类名称和颜色
- [ ] 用户可以删除分类（任务保留）
- [ ] 用户可以将任务分配到分类

### 7.4 数据导出

- [ ] 用户可以导出所有任务为 CSV
- [ ] 用户可以仅导出已完成任务

## 8. 风险评估

| 风险 | 影响 | 概率 | 应对措施 |
|------|------|------|---------|
| SQL 注入攻击 | 高 | 低 | 使用参数化查询 |
| XSS 攻击 | 中 | 中 | 输入输出转义 |
