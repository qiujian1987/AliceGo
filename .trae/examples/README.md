# AliceGo 示例项目

本目录包含基于 AliceGo 框架开发的示例项目，用于演示多 Agent 协同开发的完整流程。

## 为什么需要示例项目

### 1. 学习框架使用

示例项目展示了：

- 如何将用户需求转化为结构化文档
- 如何设计系统架构
- 如何拆分和组织代码
- 如何使用 TDD 方法开发
- 如何配置多 Agent 协作

### 2. 参考最佳实践

每个示例项目都遵循 AliceGo 的最佳实践：

- 规范的文件组织结构
- 清晰的文档命名
- 完整的开发流程
- 一致的代码风格

### 3. 快速开始

用户可以：

1. 查看示例项目结构
2. 参考文档模板
3. 学习命名规范
4. 复制示例到自己的项目

---

## 如何使用示例项目

### 1. 学习流程

建议的学习路径：

1. **阅读需求文档**：了解项目需求和功能点
2. **查看架构设计**：学习如何设计系统架构
3. **研究特性划分**：了解如何拆分大型项目
4. **参考任务拆解**：学习如何将任务分配给不同 Agent
5. **查看测试用例**：学习 TDD 开发方法

### 2. 复制示例

将示例应用到实际项目：

1. 复制示例的目录结构
2. 使用示例的文档模板
3. 遵循示例的命名规范
4. 参考示例的任务划分

### 3. 自定义示例

根据项目需求调整：

1. 修改需求文档
2. 调整架构设计
3. 添加/删除特性
4. 定制任务分配

## 示例项目结构

每个示例项目都遵循统一结构：

```
examples/
└── {项目名称}/
    ├── README.md              # 项目说明
    ├── requirements_spec.md    # 需求规约
    ├── backend_architecture.md # 后端架构
    ├── frontend_architecture.md # 前端架构
    ├── data_model.md           # 数据模型
    ├── api_contracts.md        # API 合同
    ├── project_plan.md         # 项目计划
    └── features/              # 特性目录
        └── {特性ID}/
            ├── requirements.md # 特性需求
            ├── api.md          # 特性 API
            ├── test-cases.md   # 测试用例
            └── tasks/          # 任务目录
```

## 常见问题

### Q1: 示例项目可以用于商业项目吗？

**答**：可以。示例项目的代码和文档都采用 MIT 许可证，可以自由使用和修改。

### Q2: 如何为示例项目贡献代码？

**答**：请参考 [AliceGo 贡献指南](../README.md#贡献指南)。

### Q3: 示例项目的复杂度如何划分？

**答**：
- **简单**：功能点 ≤ 5 个，特性 ≤ 3 个
- **中等**：功能点 5-15 个，特性 3-8 个
- **复杂**：功能点 > 15 个，特性 > 8 个

### Q4: 我可以基于示例创建自己的项目吗？

**答**：当然可以。示例项目只是参考，你可以根据自己的需求进行调整和扩展。
