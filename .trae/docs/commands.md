# 命令触发文档

本文档定义用户与SOLO Coder交互时使用的命令格式。

---

## 1. 命令格式

所有命令以 `/` 开头，格式如下：

```
/命令名 [参数]
```

---

## 2. 项目命令

### 2.1 开始新项目

```
/start [项目名称]
```

**示例**：
```
/start 电商网站
```

**说明**：初始化新项目，创建目录结构，初始化Git和记忆系统。

---

### 2.2 查看项目状态

```
/status
```

**示例**：
```
/status
```

**输出**：
```
[项目状态]
- 项目名称：电商网站
- 当前步骤：步骤4（需求评审）
- 进度：14%
- 迭代状态：需求评审 第1次迭代
- 状态：进行中
```

---

### 2.3 继续项目

```
/continue
```

**说明**：从上次中断的地方继续项目。

---

## 3. 流程命令

### 3.1 执行下一步

```
/next
```

**说明**：执行流程中的下一个步骤。

---

### 3.2 执行特定步骤

```
/step [步骤编号]
```

**示例**：
```
/step 4
/step 8
```

**说明**：跳转到并执行指定步骤。

---

### 3.3 重新开始步骤

```
/restart [步骤编号]
```

**示例**：
```
/restart 4
```

**说明**：重新执行指定步骤。

---

### 3.4 跳过步骤

```
/skip [步骤编号]
```

**示例**：
```
/skip 5
```

**说明**：跳过指定步骤（需要用户确认）。

---

## 4. 评审命令

### 4.1 执行评审

```
/review [评审类型]
```

**示例**：
```
/review requirements
/review design
/review test
/review code
```

**评审类型**：
| 类型 | 说明 |
|------|------|
| `requirements` | 需求评审 |
| `design` | 设计评审 |
| `test` | 测试评审 |
| `code` | 代码评审 |

---

### 4.2 查看评审结果

```
/review-status [评审类型]
```

**示例**：
```
/review-status requirements
```

---

## 5. Agent命令

### 5.1 直接调用Agent

```
@agent-name [指令]
```

**示例**：
```
@architect 请设计后端架构
@qa 请设计测试用例
@devops 请初始化项目
```

**说明**：直接调用指定的Agent执行任务。

---

### 5.2 查询Agent状态

```
/agent [agent-name]
```

**示例**：
```
/agent architect
/agent qa
```

---

## 6. 文档命令

### 6.1 查看文档

```
/doc [文档路径]
```

**示例**：
```
/doc requirements_spec.md
/doc api_contracts.md
```

---

### 6.2 验证文档

```
/validate [文档路径]
```

**示例**：
```
/validate requirements_spec.md
```

**说明**：验证文档格式和完整性。

---

## 7. 任务命令

### 7.1 查看任务列表

```
/tasks
```

**示例**：
```
/tasks
```

**输出**：
```
[任务列表]
- feature-001-task-001: 用户模块开发 [进行中]
- feature-001-task-002: 商品模块开发 [待开始]
- feature-002-task-001: 订单模块开发 [待开始]
```

---

### 7.2 查看任务详情

```
/task [任务ID]
```

**示例**：
```
/task feature-001-task-001
```

---

### 7.3 分配任务

```
/assign [任务ID] [agent-name]
```

**示例**：
```
/assign feature-001-task-001 @backend-dev
```

---

## 8. 迭代命令

### 8.1 查看迭代状态

```
/iteration [步骤编号]
```

**示例**：
```
/iteration 4
```

**输出**：
```
[迭代状态]
- 步骤：步骤4（需求评审）
- 当前迭代：2/3
- 状态：通过
- 历史：
  - 迭代1：不通过（缺少风险评估）
  - 迭代2：通过
```

---

### 8.2 重置迭代

```
/reset-iteration [步骤编号]
```

**示例**：
```
/reset-iteration 4
```

**说明**：重置指定步骤的迭代次数。

---

## 9. 帮助命令

### 9.1 查看帮助

```
/help
```

**示例**：
```
/help
/help /start
```

---

### 9.2 查看流程概览

```
/flow
```

**输出**：
```
[流程概览]
- 阶段一（1-7）：项目初始化与需求分析
- 阶段二（8-18）：系统设计
- 阶段三（19-25）：任务规划与开发
- 阶段四（26-29）：验收与交付
```

---

## 10. 自然语言交互

除了命令，用户也可以使用自然语言与SOLO Coder交互：

```
用户：我想开始一个新项目
SOLO Coder：好的，请告诉我项目名称

用户：电商网站
SOLO Coder：开始初始化项目...

用户：现在进行到哪一步了？
SOLO Coder：当前在步骤4（需求评审），需要我继续吗？

用户：帮我调用architect设计架构
SOLO Coder：好的，调用 @architect
```

---

## 11. 命令优先级

当命令与自然语言冲突时：
1. 优先执行 `/` 开头的命令
2. 自然语言作为上下文补充
