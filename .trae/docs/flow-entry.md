# 流程入口提示词

本文档为SOLO Coder提供项目启动时的引导流程。

---

## 1. 启动检测

当用户开始新对话时，SOLO Coder应自动检测：

```
1. 检查是否存在进行中的项目
2. 如果存在，读取项目状态
3. 如果不存在，显示欢迎信息
```

---

## 2. 欢迎信息

当没有进行中项目时，显示：

```
欢迎使用TRAE多Agent开发框架！

我可以帮助你：
- 🚀 从零开始开发新项目
- 📊 管理和跟踪项目进度
- 🔍 执行需求、设计、测试、代码评审
- 📝 生成各类技术文档

请告诉我你想做什么：
- 输入 "/start [项目名称]" 开始新项目
- 输入 "/help" 查看所有命令
```

---

## 3. 项目恢复检测

当检测到有进行中项目时，显示：

```
检测到进行中的项目：电商网站

[项目状态]
- 当前步骤：步骤4（需求评审）
- 进度：14%
- 状态：进行中

是否继续项目？
- 输入 "/continue" 继续项目
- 输入 "/status" 查看详细状态
- 输入 "/cancel" 取消项目
```

---

## 4. 新项目启动流程

当用户执行 `/start` 时：

```
步骤1：初始化项目
✅ 创建目录结构
✅ 初始化Git仓库
✅ 初始化记忆系统
✅ 更新项目状态

步骤2：需求分析
请描述你的项目需求：
-
```

---

## 5. 流程状态检查

每个步骤开始前，自动检查：

```
[状态检查]
1. 验证前置步骤已完成
2. 验证输入文档存在
3. 检查流程状态
4. 更新当前步骤状态
```

---

## 6. 步骤执行引导

每个步骤执行时，提供引导：

```
[步骤4：需求评审]

1. 调用 @req-reviewer 进行评审
2. 等待评审完成
3. 检查评审结果：
   - 如果通过：进入步骤5
   - 如果不通过且迭代<3次：反馈给前置Agent优化
   - 如果不通过且迭代=3次：升级用户决策
```

---

## 7. 用户确认节点

需要用户确认的节点：

```
[需要确认]

请确认以下内容：
1. 需求文档是否完整？
2. 特性划分是否合理？
3. 是否进入下一环节？

输入 "确认" 继续
输入 "取消" 取消操作
```

---

## 8. 错误处理引导

遇到错误时：

```
[错误]

问题：无法调用 @req-reviewer
原因：Agent未响应
建议：
1. 重试调用
2. 检查Agent状态：/agent req-reviewer
3. 跳过评审直接继续：/skip 4

是否重试？
```

---

## 9. 完成提示

项目完成时：

```
[项目完成]

🎉 恭喜！电商网站项目已完成！

[项目总结]
- 总步骤：29步
- 完成步骤：29步
- 总迭代：5次
- 交付物：
  - 需求文档：design/project_overview/requirements_spec.md
  - 架构文档：design/project_overview/backend_architecture.md
  - 代码：src/server/, src/client/
  - 测试：tests/

感谢使用TRAE框架！
```

---

## 10. 快捷命令参考

| 命令 | 说明 |
|------|------|
| `/start [名称]` | 开始新项目 |
| `/continue` | 继续项目 |
| `/status` | 查看状态 |
| `/next` | 执行下一步 |
| `/review [类型]` | 执行评审 |
| `/tasks` | 查看任务 |
| `/help` | 查看帮助 |
