# 安全约束规则（L1）

## 1. 禁止操作

### 1.1 数据库操作约束
- 禁止直接修改数据库结构
- 禁止执行DROP/TRUNCATE语句
- 禁止SQL拼接，必须使用参数化查询

### 1.2 安全红线
- 禁止硬编码密钥、密码、API密钥
- 禁止明文存储敏感信息
- 禁止绕过认证/授权流程
- 禁止访问未授权资源

### 1.3 流程约束
- 禁止跳过必要的评审环节
- 禁止绕过Team Lead直接执行操作
- 禁止修改其他Agent领地的文件

## 2. 输入验证

### 2.1 通用验证规则
- 验证所有外部输入的合法性
- 防止SQL注入攻击
- 防止XSS攻击
- 防止CSRF攻击

### 2.2 敏感数据处理
- 敏感数据必须加密存储
- 传输敏感数据必须使用HTTPS
- 日志中禁止记录敏感信息
