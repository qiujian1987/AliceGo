# 编码规范规则（L3）

## 1. 命名规范

### 1.1 文件命名
- 使用 kebab-case（小写字母，连字符分隔）
- 示例：`user-service.ts`、`login-form.vue`

### 1.2 组件/类命名
- 使用 PascalCase（首字母大写）
- 示例：`UserService`、`LoginForm`

### 1.3 变量/函数命名
- 使用 camelCase（首字母小写）
- 示例：`userName`、`getUserInfo`

### 1.4 常量命名
- 使用 UPPER_SNAKE_CASE（全大写，下划线分隔）
- 示例：`MAX_RETRY`、`API_BASE_URL`

## 2. 长度规范

- 函数长度：不超过 50 行
- 类/组件长度：不超过 300 行
- 文件长度：不超过 500 行
- 嵌套深度：不超过 3 层

## 3. 注释规范

### 3.1 公共 API
- 使用 JSDoc 注释
- 包含参数说明、返回值说明、示例

### 3.2 复杂逻辑
- 添加解释性注释
- 说明设计意图和决策理由

### 3.3 文件头部
- 文件说明注释
- 包含文件用途、作者、创建日期

### 3.4 维护规范
- 更新代码时同步更新注释
- 注释必须准确反映代码逻辑

## 4. 格式规范

### 4.1 代码格式化
- 使用 Prettier 自动格式化
- 统一缩进风格（4空格）
- 统一换行风格（LF）

### 4.2 语言特定规范
- TypeScript：启用 strict 模式，避免 any 类型
- Python：遵循 PEP8 规范，使用 type hints
