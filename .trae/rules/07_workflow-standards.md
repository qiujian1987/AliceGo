# 工作流程标准（L3）

## 1. 开发流程

### 1.1 核心流程
1. 需求分析 → 需求对齐 → 架构设计 → 任务分配
2. 数据模型设计 → API设计 → SQL编写 → 代码开发（TDD）
3. 代码审查 → 测试执行 → 集成部署 → 监控维护

### 1.2 TDD流程
- 先编写测试用例
- 实现代码使测试通过
- 验证测试覆盖率

## 2. 环境配置

- **开发环境**：local
- **测试环境**：staging
- **生产环境**：production

## 3. 分支策略

### 3.1 分支命名
- `main`：主分支，稳定版本
- `develop`：开发分支
- `feature/*`：特性分支
- `bugfix/*`：修复分支

### 3.2 合并流程
- 特性分支 → develop（PR审查）
- develop → main（发布前）

## 4. 发布流程

### 4.1 版本号规范
- 语义化版本：MAJOR.MINOR.PATCH
- 示例：1.0.0, 1.1.0, 1.1.1

### 4.2 发布步骤
1. 更新版本号
2. 编写发布说明
3. 执行构建验证
4. 部署到生产环境
5. 执行健康检查
