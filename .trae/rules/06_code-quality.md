# 代码质量技术标准（L3）

## 1. 准确性标准

### 1.1 语法正确性
- 生成代码必须通过语言编译/解释器检查
- TypeScript/JavaScript 通过 ESLint 检查
- Python 通过 PEP8 和 pylint 检查
- 所有代码可立即运行

### 1.2 逻辑完整性
- 边界条件处理完整
- 错误处理机制健全
- 资源释放/清理逻辑正确

## 2. 类型安全标准

### 2.1 TypeScript/JavaScript
- 启用 strict 模式
- 避免使用 any 类型
- 优先使用接口定义数据结构
- 使用泛型提高复用性

### 2.2 Python
- 使用 type hints
- 使用 dataclasses 定义数据结构
- 使用 Enum 替代魔法数字/字符串

## 3. 错误处理标准

### 3.1 异常处理
- 捕获具体异常，不使用 bare except
- 异常信息包含上下文
- 必要时记录日志
- 异常不泄露敏感信息

### 3.2 返回值设计
- 优先使用 Result/Either 模式
- 明确错误类型和成功状态
- 提供默认值的 safe fallback

## 4. 性能标准

### 4.1 资源管理
- 及时释放资源（文件、连接、内存）
- 使用连接池复用资源
- 避免内存泄漏

### 4.2 算法效率
- 选择合适的数据结构
- 避免不必要的循环嵌套
- 使用缓存减少重复计算
