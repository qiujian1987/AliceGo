# 代码可用性评审 Skill

## 功能描述

对代码进行专业的可用性评审，确保代码在错误处理、日志记录、监控指标等方面达到良好的运维标准。

## 调用规范

### 调用链路
```
SOLO Coder → 调用 @code-reviewer Agent → @code-reviewer Agent调用此Skill
```

### 约束规则
- **SOLO Coder**：必须先调用@code-reviewer Agent，**禁止**直接调用此Skill
- **@code-reviewer Agent**：负责调用此Skill执行代码可用性评审
- **Skill执行者**：@code-reviewer Agent

## 评审维度

### 1. 错误处理
- [ ] 是否捕获具体异常
- [ ] 异常信息是否包含上下文
- [ ] 是否有错误恢复机制
- [ ] 是否有重试策略
- [ ] 异常是否不泄露敏感信息

### 2. 日志记录
- [ ] 是否有结构化日志
- [ ] 日志级别是否合理
- [ ] 是否有请求追踪ID
- [ ] 是否记录关键业务指标
- [ ] 是否有日志采样策略

### 3. 监控指标
- [ ] 是否有关键指标监控
- [ ] 是否有性能指标
- [ ] 是否有错误率指标
- [ ] 是否有SLA指标
- [ ] 是否有告警阈值配置

### 4. 可观测性
- [ ] 是否支持分布式追踪
- [ ] 是否有健康检查接口
- [ ] 是否有性能剖析支持
- [ ] 是否有链路追踪
- [ ] 是否有指标暴露

### 5. 配置管理
- [ ] 是否使用配置文件
- [ ] 是否支持环境变量
- [ ] 敏感配置是否加密
- [ ] 是否有配置校验
- [ ] 是否有默认配置

### 6. 运维友好性
- [ ] 是否有启动/停止脚本
- [ ] 是否有健康检查
- [ ] 是否有优雅关闭
- [ ] 是否有资源清理
- [ ] 是否有版本信息暴露
