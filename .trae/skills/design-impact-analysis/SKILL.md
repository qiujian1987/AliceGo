# 关联影响分析 Skill

## 功能描述

对设计方案进行全面的影响分析，识别潜在的关联影响，评估变更范围，帮助做出更明智的设计决策。

## 调用规范

### 调用链路
```
SOLO Coder → 调用 @design-reviewer Agent → @design-reviewer Agent调用此Skill
```

### 约束规则
- **SOLO Coder**：必须先调用@design-reviewer Agent，**禁止**直接调用此Skill
- **@design-reviewer Agent**：负责调用此Skill执行关联影响分析
- **Skill执行者**：@design-reviewer Agent

## 分析维度

### 1. 模块依赖影响
- [ ] 识别直接依赖的模块
- [ ] 识别间接依赖的模块
- [ ] 评估依赖模块的变更风险
- [ ] 检查是否存在循环依赖

### 2. 接口影响
- [ ] 识别受影响的API接口
- [ ] 评估接口兼容性
- [ ] 检查是否需要版本升级
- [ ] 评估对客户端的影响

### 3. 数据影响
- [ ] 识别数据模型变更
- [ ] 评估数据迁移需求
- [ ] 检查数据兼容性
- [ ] 评估数据完整性风险

### 4. 第三方依赖影响
- [ ] 识别第三方服务依赖
- [ ] 评估服务可用性要求
- [ ] 检查SLA要求
- [ ] 评估集成风险

### 5. 部署影响
- [ ] 评估部署顺序要求
- [ ] 识别停机时间需求
- [ ] 检查回滚方案
- [ ] 评估部署风险

### 6. 安全影响
- [ ] 识别安全边界变更
- [ ] 评估认证授权影响
- [ ] 检查数据泄露风险
- [ ] 评估合规性影响

### 4. 风险评估汇总
