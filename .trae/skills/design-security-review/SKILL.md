# 设计安全评审 Skill

## 功能描述

对系统设计进行全面的安全评审，识别潜在的安全风险，确保设计方案符合安全最佳实践和合规要求。

## 调用规范

### 调用链路
```
SOLO Coder → 调用 @design-reviewer Agent → @design-reviewer Agent调用此Skill
```

### 约束规则
- **SOLO Coder**：必须先调用@design-reviewer Agent，**禁止**直接调用此Skill
- **@design-reviewer Agent**：负责调用此Skill执行设计安全评审
- **Skill执行者**：@design-reviewer Agent

## 评审维度

### 1. 认证与授权
- [ ] 是否有完善的认证机制
- [ ] 是否支持多因素认证
- [ ] 是否有细粒度的授权控制
- [ ] 是否考虑权限继承和层级
- [ ] 是否有会话管理机制

### 2. 数据安全
- [ ] 敏感数据是否加密存储
- [ ] 数据传输是否使用HTTPS
- [ ] 是否有数据脱敏方案
- [ ] 是否有数据备份和恢复策略
- [ ] 是否有数据访问审计

### 3. 访问控制
- [ ] 是否有最小权限原则
- [ ] 是否有访问控制列表(ACL)
- [ ] 是否考虑角色基访问控制(RBAC)
- [ ] 是否有API访问限制

### 4. 输入验证
- [ ] 是否有完整的输入验证
- [ ] 是否防止SQL注入
- [ ] 是否防止XSS攻击
- [ ] 是否防止CSRF攻击
- [ ] 是否处理文件上传安全

### 5. 安全日志与监控
- [ ] 是否有安全事件日志
- [ ] 是否有异常行为检测
- [ ] 是否有告警机制
- [ ] 是否有安全审计能力

### 6. 合规性
- [ ] 是否符合行业安全标准
- [ ] 是否满足GDPR要求（如适用）
- [ ] 是否满足行业合规要求
- [ ] 是否有安全策略文档
