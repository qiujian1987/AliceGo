# 代码规范评审 Skill

## 功能描述

对代码进行专业的规范评审，确保代码符合团队编码规范，提高代码的可读性和可维护性。

## 调用规范

### 调用链路
```
SOLO Coder → 调用 @code-reviewer Agent → @code-reviewer Agent调用此Skill
```

### 约束规则
- **SOLO Coder**：必须先调用@code-reviewer Agent，**禁止**直接调用此Skill
- **@code-reviewer Agent**：负责调用此Skill执行代码规范评审
- **Skill执行者**：@code-reviewer Agent

## 评审维度

### 1. 命名规范
- [ ] 文件/文件夹命名：kebab-case
- [ ] 类/组件命名：PascalCase
- [ ] 变量/函数命名：camelCase
- [ ] 常量命名：UPPER_SNAKE_CASE
- [ ] 接口/类型命名：I前缀 + PascalCase

### 2. 代码格式
- [ ] 缩进统一（空格/制表符）
- [ ] 行长度符合规范
- [ ] 空行使用合理
- [ ] 大括号位置正确
- [ ] 逗号后空格

### 3. 注释规范
- [ ] 公共API有JSDoc注释
- [ ] 复杂逻辑有解释性注释
- [ ] 文件头部有说明
- [ ] 注释与代码同步
- [ ] 避免冗余注释

### 4. 架构模式
- [ ] 遵循单一职责原则
- [ ] 避免循环依赖
- [ ] 模块划分清晰
- [ ] 依赖注入使用合理
- [ ] 设计模式应用恰当

### 5. 代码组织
- [ ] 函数长度不超过50行
- [ ] 文件长度不超过500行
- [ ] 嵌套深度不超过3层
- [ ] 导入顺序合理
- [ ] 变量声明位置合理
