# 需求清晰度评审 Skill

## 功能描述

对需求文档进行清晰度评审，确保需求描述明确、无歧义、可验证，并且优先级清晰。

## 调用规范

### 调用链路
```
SOLO Coder → 调用 @req-reviewer Agent → @req-reviewer Agent调用此Skill
```

### 约束规则
- **SOLO Coder**：必须先调用@req-reviewer Agent，**禁止**直接调用此Skill
- **@req-reviewer Agent**：负责调用此Skill执行需求清晰度评审
- **Skill执行者**：@req-reviewer Agent

## 评审维度

### 1. 描述明确性
- [ ] 是否使用清晰的动词
- [ ] 是否有明确的主语
- [ ] 是否避免模糊词汇
- [ ] 是否有明确的时间范围
- [ ] 是否有明确的范围界定

### 2. 无歧义性
- [ ] 是否有多种理解可能
- [ ] 是否有二义性词汇
- [ ] 是否有冲突的描述
- [ ] 是否有矛盾的需求
- [ ] 是否有重叠的需求

### 3. 可验证性
- [ ] 是否有明确的验收标准
- [ ] 是否有可测试的场景
- [ ] 是否有量化指标
- [ ] 是否有明确的成功条件
- [ ] 是否有明确的失败条件

### 4. 优先级明确
- [ ] 是否有优先级标记
- [ ] 是否区分核心和次要需求
- [ ] 是否有时间优先级
- [ ] 是否有业务优先级
- [ ] 是否有依赖优先级

### 5. 格式规范
- [ ] 是否遵循命名规范
- [ ] 是否有统一的编号
- [ ] 是否有清晰的结构
- [ ] 是否有必要的文档要素
- [ ] 是否有版本控制
