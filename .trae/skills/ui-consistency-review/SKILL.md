# 设计一致性评审 Skill

## 功能描述

对UI设计进行专业的一致性评审，确保设计风格统一、组件复用合理、设计系统得到良好遵循。

## 调用规范

### 调用链路
```
SOLO Coder → 调用 @ui-ux-reviewer Agent → @ui-ux-reviewer Agent调用此Skill
```

### 约束规则
- **SOLO Coder**：必须先调用@ui-ux-reviewer Agent，**禁止**直接调用此Skill
- **@ui-ux-reviewer Agent**：负责调用此Skill执行设计一致性评审
- **Skill执行者**：@ui-ux-reviewer Agent

## 评审维度

### 1. 风格一致性
- [ ] 颜色方案是否统一
- [ ] 字体样式是否一致
- [ ] 图标风格是否统一
- [ ] 间距规范是否遵循
- [ ] 圆角风格是否一致

### 2. 组件复用
- [ ] 是否使用统一的组件库
- [ ] 组件样式是否一致
- [ ] 是否有重复造轮子
- [ ] 组件变体是否规范
- [ ] 组件行为是否一致

### 3. 设计系统遵循
- [ ] 是否遵循设计系统
- [ ] 设计令牌是否使用
- [ ] 组件库版本是否统一
- [ ] 设计模式是否一致
- [ ] 是否有设计偏差

### 4. 品牌一致性
- [ ] Logo使用是否规范
- [ ] 品牌颜色是否正确
- [ ] 品牌字体是否使用
- [ ] 品牌风格是否统一
- [ ] 是否有品牌冲突

### 5. 交互模式一致性
- [ ] 按钮样式是否统一
- [ ] 表单交互是否一致
- [ ] 弹窗样式是否统一
- [ ] 导航模式是否一致
- [ ] 反馈模式是否统一
