# 代码性能评审 Skill

## 功能描述

对代码进行专业的性能评审，识别性能瓶颈，提出优化建议，确保代码在性能方面达到高质量标准。

## 调用规范

### 调用链路
```
SOLO Coder → 调用 @code-reviewer Agent → @code-reviewer Agent调用此Skill
```

### 约束规则
- **SOLO Coder**：必须先调用@code-reviewer Agent，**禁止**直接调用此Skill
- **@code-reviewer Agent**：负责调用此Skill执行代码性能评审
- **Skill执行者**：@code-reviewer Agent

## 评审维度

### 1. 算法复杂度
- [ ] 时间复杂度评估
- [ ] 空间复杂度评估
- [ ] 是否有O(n²)及以上的低效算法
- [ ] 排序算法选择是否合理
- [ ] 是否有不必要的重复计算

### 2. 资源使用
- [ ] 内存使用是否合理
- [ ] 对象创建是否过度
- [ ] 资源释放是否及时
- [ ] 是否有内存泄漏风险
- [ ] 是否有不必要的全局状态

### 3. 缓存策略
- [ ] 是否有缓存机制
- [ ] 缓存策略是否合理
- [ ] 缓存过期策略是否完善
- [ ] 是否有缓存穿透/击穿/雪崩风险
- [ ] 是否有数据一致性保障

### 4. 并发处理
- [ ] 并发控制是否合理
- [ ] 锁的使用是否正确
- [ ] 是否有死锁风险
- [ ] 是否有竞态条件
- [ ] 是否支持异步处理

### 5. 数据库操作
- [ ] SQL查询是否优化
- [ ] 是否有N+1查询问题
- [ ] 索引使用是否合理
- [ ] 是否有大量数据的内存操作
- [ ] 是否支持分页

### 6. I/O操作
- [ ] 是否有阻塞I/O操作
- [ ] 是否支持批量操作
- [ ] 是否有超时控制
- [ ] 是否有重试机制
