# 业务逻辑设计评审 Skill

## 功能描述

对系统设计中的业务逻辑进行专业评审，确保设计方案与业务需求一致，业务流程合理，状态转换正确。

## 调用规范

### 调用链路
```
SOLO Coder → 调用 @design-reviewer Agent → @design-reviewer Agent调用此Skill
```

### 约束规则
- **SOLO Coder**：必须先调用@design-reviewer Agent，**禁止**直接调用此Skill
- **@design-reviewer Agent**：负责调用此Skill执行业务逻辑设计评审
- **Skill执行者**：@design-reviewer Agent

## 评审维度

### 1. 需求匹配度
- [ ] 设计是否覆盖所有功能需求
- [ ] 设计是否符合业务目标
- [ ] 设计是否满足用户故事描述
- [ ] 是否有遗漏的业务场景

### 2. 业务流程设计
- [ ] 主业务流程是否清晰合理
- [ ] 分支流程是否完整
- [ ] 异常流程是否考虑周全
- [ ] 流程是否符合业务规范

### 3. 状态转换
- [ ] 状态定义是否清晰
- [ ] 状态转换是否完整
- [ ] 状态转换是否符合业务规则
- [ ] 是否有非法状态转换

### 4. 业务规则
- [ ] 业务规则是否明确
- [ ] 规则之间是否冲突
- [ ] 规则是否可执行
- [ ] 规则是否符合业务领域知识

### 5. 数据模型与业务匹配
- [ ] 实体设计是否符合业务概念
- [ ] 关系设计是否正确
- [ ] 属性设计是否完整
- [ ] 是否有冗余或缺失的实体
