# 代码安全评审 Skill

## 功能描述

对代码进行专业的安全评审，识别潜在的安全漏洞和风险，确保代码符合安全最佳实践。

## 调用规范

### 调用链路
```
SOLO Coder → 调用 @code-reviewer Agent → @code-reviewer Agent调用此Skill
```

### 约束规则
- **SOLO Coder**：必须先调用@code-reviewer Agent，**禁止**直接调用此Skill
- **@code-reviewer Agent**：负责调用此Skill执行代码安全评审
- **Skill执行者**：@code-reviewer Agent

## 评审维度

### 1. 输入验证
- [ ] 所有外部输入是否验证
- [ ] 验证是否充分（类型、长度、格式）
- [ ] 是否使用白名单验证
- [ ] 文件上传是否验证
- [ ] 是否有路径遍历防护

### 2. SQL注入防护
- [ ] 是否使用参数化查询
- [ ] 是否禁止SQL拼接
- [ ] ORM使用是否正确
- [ ] 动态SQL是否安全
- [ ] 是否有存储过程注入风险

### 3. XSS防护
- [ ] 用户输入是否转义
- [ ] HTML输出是否安全
- [ ] 是否使用安全的模板引擎
- [ ] 是否有DOM XSS风险
- [ ] 是否有富文本处理风险

### 4. 敏感信息处理
- [ ] 敏感信息是否加密存储
- [ ] 是否明文记录敏感信息
- [ ] 日志中是否有敏感信息泄露
- [ ] 密码是否使用强哈希算法
- [ ] 是否有密钥硬编码

### 5. 认证与授权
- [ ] 是否有认证检查
- [ ] 是否有权限验证
- [ ] 是否有会话固定攻击防护
- [ ] Token是否安全存储
- [ ] 是否有CSRF防护

### 6. 安全配置
- [ ] 是否禁用调试模式
- [ ] 是否有安全的CORS配置
- [ ] 是否有安全的CSP配置
- [ ] 是否有安全的Cookie标志
- [ ] 是否有HTTPS强制
