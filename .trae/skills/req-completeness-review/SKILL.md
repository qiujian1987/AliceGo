# 需求完整性评审 Skill

## 功能描述

对需求文档进行完整性评审，确保所有功能需求、边界条件、异常场景和数据需求都被充分考虑和描述。

## 调用规范

### 调用链路
```
SOLO Coder → 调用 @req-reviewer Agent → @req-reviewer Agent调用此Skill
```

### 约束规则
- **SOLO Coder**：必须先调用@req-reviewer Agent，**禁止**直接调用此Skill
- **@req-reviewer Agent**：负责调用此Skill执行需求完整性评审
- **Skill执行者**：@req-reviewer Agent

## 评审维度

### 1. 功能需求覆盖
- [ ] 是否覆盖所有核心功能
- [ ] 是否覆盖辅助功能
- [ ] 是否覆盖用户故事中的所有场景
- [ ] 是否有遗漏的业务流程
- [ ] 是否覆盖正向和反向流程

### 2. 边界条件
- [ ] 是否考虑输入边界
- [ ] 是否考虑输出边界
- [ ] 是否考虑数据量边界
- [ ] 是否考虑性能边界
- [ ] 是否考虑时间边界

### 3. 异常场景
- [ ] 是否考虑系统异常
- [ ] 是否考虑业务异常
- [ ] 是否考虑网络异常
- [ ] 是否考虑数据异常
- [ ] 是否考虑权限异常

### 4. 数据需求
- [ ] 是否定义数据实体
- [ ] 是否定义数据关系
- [ ] 是否定义数据格式
- [ ] 是否定义数据量
- [ ] 是否定义数据安全性

### 5. 接口需求
- [ ] 是否定义内部接口
- [ ] 是否定义外部接口
- [ ] 是否定义API规格
- [ ] 是否定义数据交换格式
- [ ] 是否定义接口协议
