# 业务逻辑正确性评审 Skill

## 功能描述

检查代码中业务逻辑的正确性，确保业务流程、业务规则、状态转换等完全符合需求文档和特性需求中的要求，避免业务逻辑错误。

## 调用规范

### 调用链路
```
SOLO Coder → 调用 @code-reviewer Agent → @code-reviewer Agent调用此Skill
```

### 约束规则
- **SOLO Coder**：必须先调用@code-reviewer Agent，**禁止**直接调用此Skill
- **@code-reviewer Agent**：负责调用此Skill执行业务逻辑评审
- **Skill执行者**：@code-reviewer Agent

## 评审维度

### 1. 业务流程完整性
- [ ] 主要业务流程是否完整实现
- [ ] 分支流程是否覆盖所有场景
- [ ] 异常流程是否正确处理
- [ ] 用户故事中的流程是否都已实现
- [ ] 流程跳转逻辑是否正确

### 2. 业务规则正确性
- [ ] 所有业务规则是否正确实现
- [ ] 计算公式是否正确
- [ ] 条件判断逻辑是否符合业务要求
- [ ] 数据验证规则是否完整
- [ ] 权限检查逻辑是否正确

### 3. 状态转换正确性
- [ ] 状态机定义是否与设计一致
- [ ] 状态转换条件是否正确
- [ ] 状态转换触发条件是否完整
- [ ] 是否存在非法状态转换
- [ ] 状态转换的前置/后置条件是否验证

### 4. 数据一致性保证
- [ ] 多步操作的事务处理是否正确
- [ ] 数据回滚机制是否完善
- [ ] 并发场景下的数据一致性是否考虑
- [ ] 关联数据的同步更新是否正确
- [ ] 数据完整性约束是否保证

### 5. 边界条件处理
- [ ] 最大值/最小值场景是否处理
- [ ] 空值/零值场景是否处理
- [ ] 边界日期/时间是否处理
- [ ] 批量操作的边界是否考虑
- [ ] 容量限制是否正确实现

### 6. 验收标准覆盖
- [ ] 所有验收标准是否都有对应的实现
- [ ] 成功场景是否验证
- [ ] 失败场景是否验证
- [ ] 边界场景是否验证
- [ ] 异常场景是否验证
