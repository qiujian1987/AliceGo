# 界面布局评审 Skill

## 功能描述

对UI设计进行专业的布局评审，确保界面布局合理、视觉层级清晰、留白恰当、响应式设计完善。

## 调用规范

### 调用链路
```
SOLO Coder → 调用 @ui-ux-reviewer Agent → @ui-ux-reviewer Agent调用此Skill
```

### 约束规则
- **SOLO Coder**：必须先调用@ui-ux-reviewer Agent，**禁止**直接调用此Skill
- **@ui-ux-reviewer Agent**：负责调用此Skill执行界面布局评审
- **Skill执行者**：@ui-ux-reviewer Agent

## 评审维度

### 1. 页面结构
- [ ] 页面结构是否清晰
- [ ] 是否有明确的信息层级
- [ ] 模块划分是否合理
- [ ] 导航是否直观
- [ ] 信息架构是否清晰

### 2. 视觉层级
- [ ] 重要信息是否突出
- [ ] 视觉权重是否合理
- [ ] 信息优先级是否明确
- [ ] 颜色对比是否恰当
- [ ] 字体层级是否清晰

### 3. 留白设计
- [ ] 留白是否适当
- [ ] 元素间距是否均匀
- [ ] 是否避免拥挤
- [ ] 呼吸空间是否充足
- [ ] 留白是否有意义

### 4. 对齐规范
- [ ] 元素对齐是否一致
- [ ] 网格系统是否遵循
- [ ] 边距是否统一
- [ ] 排版基线是否对齐
- [ ] 视觉平衡是否良好

### 5. 响应式设计
- [ ] 是否适配多种屏幕尺寸
- [ ] 布局是否自适应
- [ ] 断点设置是否合理
- [ ] 移动端体验是否良好
- [ ] 是否有布局塌陷问题
