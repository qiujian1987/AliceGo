# DFX设计评审 Skill

## 功能描述

对系统设计进行DFX（Design for X）评审，确保设计方案在可维护性、可扩展性、可测试性、可部署性等方面达到高质量标准。

## 调用规范

### 调用链路
```
SOLO Coder → 调用 @design-reviewer Agent → @design-reviewer Agent调用此Skill
```

### 约束规则
- **SOLO Coder**：必须先调用@design-reviewer Agent，**禁止**直接调用此Skill
- **@design-reviewer Agent**：负责调用此Skill执行DFX设计评审
- **Skill执行者**：@design-reviewer Agent

## 评审维度

### 1. 可维护性 (Maintainability)
- [ ] 模块职责是否单一
- [ ] 代码复杂度是否可控
- [ ] 文档是否完整
- [ ] 错误处理是否清晰
- [ ] 日志是否充足

### 2. 可扩展性 (Extensibility)
- [ ] 是否采用模块化设计
- [ ] 是否支持插件化扩展
- [ ] 是否使用接口抽象
- [ ] 耦合度是否合理
- [ ] 是否考虑未来需求变化

### 3. 可测试性 (Testability)
- [ ] 模块是否易于单元测试
- [ ] 是否有明确的测试接口
- [ ] 是否依赖外部资源难以测试
- [ ] 是否支持测试数据隔离

### 4. 可部署性 (Deployability)
- [ ] 是否支持容器化部署
- [ ] 是否有配置管理方案
- [ ] 是否支持蓝绿部署/滚动更新
- [ ] 是否有健康检查机制

### 5. 可靠性 (Reliability)
- [ ] 是否有容错机制
- [ ] 是否有重试策略
- [ ] 是否考虑降级方案
- [ ] 是否有监控告警设计

### 6. 性能 (Performance)
- [ ] 是否考虑性能瓶颈
- [ ] 是否有缓存策略
- [ ] 是否支持异步处理
- [ ] 数据库查询是否优化
