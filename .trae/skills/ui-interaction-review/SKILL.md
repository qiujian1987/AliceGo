# 交互设计评审 Skill

## 功能描述

对UI设计进行专业的交互评审，确保用户流程顺畅、操作反馈及时、错误处理友好、整体可用性高。

## 调用规范

### 调用链路
```
SOLO Coder → 调用 @ui-ux-reviewer Agent → @ui-ux-reviewer Agent调用此Skill
```

### 约束规则
- **SOLO Coder**：必须先调用@ui-ux-reviewer Agent，**禁止**直接调用此Skill
- **@ui-ux-reviewer Agent**：负责调用此Skill执行交互设计评审
- **Skill执行者**：@ui-ux-reviewer Agent

## 评审维度

### 1. 用户流程
- [ ] 流程是否直观
- [ ] 步骤是否简洁
- [ ] 是否有不必要的步骤
- [ ] 是否支持快捷操作
- [ ] 是否支持撤销/回退

### 2. 操作反馈
- [ ] 是否有即时反馈
- [ ] 加载状态是否提示
- [ ] 操作成功是否确认
- [ ] 进度指示是否清晰
- [ ] 按钮状态是否反馈

### 3. 错误处理
- [ ] 错误提示是否清晰
- [ ] 是否有错误引导
- [ ] 是否有容错机制
- [ ] 是否支持错误恢复
- [ ] 错误信息是否友好

### 4. 可用性
- [ ] 是否符合用户习惯
- [ ] 是否有操作指引
- [ ] 是否有帮助文档
- [ ] 是否支持键盘操作
- [ ] 是否有可访问性考虑

### 5. 微交互
- [ ] 动画是否流畅
- [ ] 过渡效果是否自然
- [ ] 悬停效果是否恰当
- [ ] 焦点状态是否明显
- [ ] 微交互是否有意义
