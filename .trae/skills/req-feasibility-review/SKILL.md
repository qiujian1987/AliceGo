# 需求可行性评审 Skill

## 功能描述

对需求进行可行性评审，评估技术实现的可行性、资源需求、时间估算和潜在风险，确保需求可以在预期的约束条件下完成。

## 调用规范

### 调用链路
```
SOLO Coder → 调用 @req-reviewer Agent → @req-reviewer Agent调用此Skill
```

### 约束规则
- **SOLO Coder**：必须先调用@req-reviewer Agent，**禁止**直接调用此Skill
- **@req-reviewer Agent**：负责调用此Skill执行需求可行性评审
- **Skill执行者**：@req-reviewer Agent

## 评审维度

### 1. 技术可行性
- [ ] 是否有成熟的技术方案
- [ ] 是否有技术难点
- [ ] 是否有技术风险
- [ ] 是否需要新技术
- [ ] 是否有技术栈匹配问题

### 2. 资源估算
- [ ] 是否有人力资源评估
- [ ] 是否有时间资源评估
- [ ] 是否有预算评估
- [ ] 是否有外部依赖评估
- [ ] 是否有工具资源评估

### 3. 时间估算
- [ ] 是否有合理的时间预估
- [ ] 是否有里程碑规划
- [ ] 是否有缓冲时间
- [ ] 是否有风险预留
- [ ] 是否有依赖关系考虑

### 4. 风险评估
- [ ] 是否有技术风险
- [ ] 是否有业务风险
- [ ] 是否有外部风险
- [ ] 是否有合规风险
- [ ] 是否有安全风险

### 5. 依赖分析
- [ ] 是否有内部依赖
- [ ] 是否有外部依赖
- [ ] 是否有第三方依赖
- [ ] 是否有数据依赖
- [ ] 是否有时序依赖
